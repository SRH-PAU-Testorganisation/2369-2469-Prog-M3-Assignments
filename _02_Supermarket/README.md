# Supermarkt

## Aufgabe 1: Bauen Sie mithilfe von OOP einen simplen Supermarkt.
Ihr Supermarkt besteht aus **Produkten**, die alle einen **Namen** und einen **Preis** haben.
Der Name eines Produkts darf nach der Instanziierung gelesen, aber nicht mehr geändert werden.
Der Preis darf gelesen und geändert werden.

Definieren Sie Ihren Produktkatalog in Ihrer Main-Methode mit einem Array aus Produkten.

## Aufgabe 2: Ausgabe
Geben Sie die Informationen für jedes Produkt aus Ihrem Array in der Konsole aus.
- Wo würden Sie Ihr `println()`-Statments unterbringen?
- Wo würden Sie die Informationen eines Produkts zu einem String zusammenfügen?

## Aufgabe 3: Summe
Geben Sie am Ende noch einmal die Summe aller Preise Ihrer Produkte aus (jedes Produkt existiert nur einmal).

## Aufgabe 4: Feature ergänzen
Wie würde man noch ein Attribut `quantity` (Menge) ergänzen? Welche Stellen im Code müssten angepasst werden?
